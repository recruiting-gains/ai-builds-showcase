# AI Builds Showcase

A public collection of practical AI tools, workflow experiments, and original interfaces.

| Project | What it explores | Stack |
| --- | --- | --- |
| [Memory City](./memory-city) | Turns notes into a living 3D city of ideas, districts, and connections | Cloudflare Workers, Workers AI, D1, Vectorize, Three.js, TypeScript |
| [Explain It Visually](./explain-it-visually) | Turns plain-language explanations into editable, downloadable infographics | Cloudflare Workers, Workers AI, AntV Infographic, TypeScript |
| [AI Workflow Lab](./ai-workflow-lab) | Two simple, full-stack AI automations with structured output | Cloudflare Workers, Workers AI, TypeScript, HTML/CSS/JS |
| [ChatGPT Ads](./chatgpt-ads) ([live](https://chatgpt-ads.recruiting-gains.workers.dev/)) | A transparent, rule-based campaign health check for ad exports | Next.js, OpenNext, Cloudflare Workers, TypeScript |

These are independent, original projects. They are not affiliated with GitHub,
Cloudflare, OpenAI, or any other product shown or discussed.
