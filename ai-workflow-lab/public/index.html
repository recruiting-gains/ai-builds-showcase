        UNDER THE HOOD
        
            
        One small architecture, used twice.
        
          
        
          
        
            Learn this pattern once and you can reuse it for dozens of school and
            personal projects.
          
        
        
        

        
        
          
        
            01
            FRONT END
            HTML, CSS & JavaScript
            
        Collects the input and renders safe, editable results.
        
          
        
          
        
            validated JSON
            →
          
        
          
        
            02
            BACK END
            Cloudflare Worker
            
        Checks requests, protects limits, and chooses the prompt.
        
          
        
          
        
            one AI call
            →
          
        
          
        
            03
            MODEL
            Workers AI
            
        Returns a fixed JSON schema the interface can trust.
        
          
        
        
        

        
        
          
        
            ◇
            
        No database
        
            
        Nothing to migrate, manage, or accidentally expose while learning.
        
          
        
          
        
            ⌁
            
        No browser API key
        
            
        The AI binding stays on the Worker, away from front-end source code.
        
          
        
          
        
            ✓
            
        Structured output
        
            
        A JSON schema makes every field predictable and easy to render.
        
          
        
          
        
            ↗
            
        One-command deploy
        
            
        The static site and API publish together on Cloudflare’s network.
        
          
        
        
        
      
        

      
        
        
        
          
        
            
        WHY THESE TWO?
        
            
        Easy to reverse engineer. Useful enough to keep.
        
          
        
          
        
            
        
              Both workflows have a single input, one AI transformation, and a
              visible output. That makes them ideal for learning where the front
              end stops, where the API begins, and what the model actually does.
